# 📊 پنل مدیریت مالی | Financial Management Dashboard

یک داشبورد جامع، مدرن و کاملاً واکنش‌گرا (Responsive) برای مدیریت تراکنش‌های مالی، سفارش‌ها، گزارش‌های سود و زیان و کاربران که با **HTML5 معنایی**، **Tailwind CSS v4** و **جاوااسکریپت خالص (Vanilla JS)** طراحی شده است.

---

## ✨ ویژگی‌های برجسته (Key Features)

- 🌗 **پشتیبانی کامل از حالت تاریک و روشن (Dark / Light Mode)** با تشخیص خودکار تم سیستم و ذخیره در LocalStorage بدون پرش تصویر (Zero-FOUC).
- 📱 **سایدبار موبایل با جسچر لمسی نیتیو (Touch Swipe Drawer)** و فیزیک حرکتی روان ۱ به ۱ منطبق با چینش راست‌به‌چپ (RTL).
- 🌊 **محوشدگی نرم انتهای جدول‌های مالی (CSS Masking Gradient)** جهت نمایش بصری ادامه‌دار بودن ستون‌ها در اسکرول افقی.
- ⚡ **انیمیشن‌های ملایم اسکرول (CSS Scroll-Driven Animations)** مبتنی بر شتاب‌دهنده گرافیکی (GPU) بدون نیاز به کتابخانه‌های سنگین JS.
- ♿ **رعایت کامل استانداردهای دسترسی‌پذیری (WCAG 2.2 AAA)**: کنتراست بالای رنگ‌ها، تگ‌های معنایی `<dialog>` برای مودال‌ها و کنترل برچسب‌های فرم.
- 🎯 **تایپوگرافی متوازن فارسی**: استفاده از `text-wrap: balance` و `text-wrap: pretty` برای جلوگیری از افتادن تک‌کلمه‌ای متن‌ها در خط بعد.
- 🚀 **آماده دیپلوی آنی روی Netlify**: مجهز به کانفیگ بهینه `netlify.toml`، ریدایرکت‌های سریع CDN و هدرهای امنیتی مدرن.

## 📑 صفحات پروژه (Pages)

| صفحه | فایل | توضیحات |
| :--- | :--- | :--- |
| **پیشخوان** | `pages/dashboard.html` | کارت‌های آماری، نمودار درآمد ماهانه/سالانه، لودینگ اسکلتون و تراکنش‌های زنده |
| **سفارش‌ها** | `pages/orders.html` | مدیریت وضعیت سفارش‌ها، درگاه‌های پرداخت، مودال صدور پیش‌فاکتور با قابلیت چاپ |
| **کاربران** | `pages/users.html` | باشگاه مشتریان VIP، سطوح کاربری، پرونده مالی و موجودی کیف‌پول |
| **تراکنش‌ها** | `pages/transactions.html` | رهگیری تراکنش‌های بانکی شاپرک (کد RRN)، صورت مغایرت و فیلترهای پیشرفته |
| **گزارش‌ها** | `pages/reports.html` | نمودار برداری مقایسه‌ای درآمد و هزینه، صورت سود و زیان (P&L) و تحلیل عملکرد |
| **تنظیمات** | `pages/settings.html` | پیکربندی درگاه‌های بانکی، مالیات بر ارزش افزوده (VAT)، وب‌سرویس پیامکی و امنیت |

## 🛠️ تکنولوژی‌ها (Tech Stack)

- **ساختار**: HTML5 Semantic Elements, Native `<dialog>`
- **استایل‌دهی**: Tailwind CSS v4 + Vanilla Modern CSS
- **فونت و آیکون**: فونت ساحل (Sahel)، FontAwesome Free 7 (با اعتبارسنجی SRI)
- **منطق تعاملی**: Vanilla JavaScript (ES6+)
- **هاستینگ و استقرار**: Netlify Edge CDN

## 🚀 راه‌اندازی لوکال (Quick Start)

۱. کلون کردن مخزن:

```bash
git clone https://github.com/USERNAME/REPO_NAME.git
cd REPO_NAME
```

۲. نصب وابستگی‌های پکیج‌ها:

```bash
npm install
```

۳. اجرای دستور بیلد استایل‌های تیلویند:

```bash
npm run build
```

۴. اجرای پروژه:
فایل `index.html` را مستقیماً در مرورگر باز کنید یا با یک لایو سرور محلی (مانند افزونه Live Server یا `npx serve .`) اجرا نمایید.
